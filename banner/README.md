# CodeMolecule Official Standee Banner (4ft × 2ft)

একটি প্রফেশনাল, আধুনিক এবং হাই-রেজোলিউশন ৪ ফুট × ২ ফুট (Height: 4 ft, Width: 2 ft) স্ট্যান্ডি/রোল-আপ ব্যানার। এটি কোডমলিকিউল (`codemolecule.com`) ওয়েবসাইটের থিম, কালার প্যালেট, টাইপোগ্রাফি এবং ব্র্যান্ড আইডেন্টিটির সাথে ১০০% মিল রেখে তৈরি করা হয়েছে।

---

## 📁 ফাইল পরিচিতি (File Structure)

- **`index.html`** — মূল ইন্টারেক্টিভ ব্যানার ফাইল। যে কোনো ব্রাউজারে (Chrome, Brave, Firefox, Safari) সরাসরি ডাবল ক্লিক করে ওপেন করা যায়। এতে ডার্ক/লাইট থিম টগল, জুম কন্ট্রোল এবং ১-ক্লিক প্রিন্ট/পিডিএফ এক্সপোর্ট সুবিধা রয়েছে।
- **`codemolecule-banner.png`** — হাই-রেজোলিউশন **Dark Tech Edition** PNG (প্রাইমারি রেন্ডার, প্রিন্ট ও প্রিভিউয়ের জন্য রেডি)।
- **`codemolecule-banner-light.png`** — হাই-রেজোলিউশন **Light Canvas Edition** PNG (দিনের বেলা বা লাইট ব্যাকগ্রাউন্ড ইভেন্টের জন্য)।
- **`qr.svg`** — ভেক্টর SVG ফরম্যাটে জেনারেট করা হাই-কোয়ালিটি QR কোড (স্ক্যান করলে সরাসরি `https://codemolecule.com`-এ নিয়ে যাবে)।
- **`export-banners.js`** — নোড জেএস স্ক্রিপ্ট, যা দিয়ে যে কোনো সময় কমান্ডের মাধ্যমে পুনরায় ব্যানার পিএনজি জেনারেট করা যায় (`node export-banners.js`)।
- **`tech-icons.json`** — টেকনোলজি স্ট্যাকের অফিসিয়াল ভেক্টর আইকন ডেটা।

## 📱 QR কোড বিবরণ (QR Code Details)

- ব্যানারের নিচের ডান পাশে একটি স্পষ্ট, হাই-কন্ট্রাস্ট কিউআর কোড বক্স রাখা হয়েছে।
- যেকোনো স্মার্টফোনের ক্যামেরা (iPhone Camera বা Android Google Lens) দিয়ে পয়েন্ট করলেই এটি সরাসরি **`https://codemolecule.com`** ওয়েবসাইটে নিয়ে যাবে।
- কিউআর কোডটি ভেক্টর SVG হিসেবে যুক্ত থাকায় প্রিন্ট করার সময় কোনো প্রকার ব্লার বা পিক্সেল ভাঙবে না।

## 🖨️ প্রিন্ট করার নিয়ম (How to Print / Export PDF)

1. ব্রাউজারে [index.html](file:///mnt/434021C97D7AFC13/dorkar/banner/index.html) ফাইলটি ওপেন করুন।
2. উপরের টুলবারের **"🖨️ Print / Save PDF"** বাটনে ক্লিক করুন (অথবা কিবোর্ডে `Ctrl + P` চাপুন)।
3. প্রিন্ট সেটিংস উইন্ডোতে:
   - **Destination**: *Save as PDF* অথবা আপনার প্রিন্টার নির্বাচন করুন।
   - **Paper Size**: *Custom* (24 × 48 in) অথবা *Tabloid / Large Format*।
   - **Background Graphics**: টিক চিহ্ন দিন (Check ✅)।
   - **Margins**: *None*।
4. ব্যানারটি সরাসরি ডিজিটাল প্রিন্ট শপে পাঠানোর জন্য `codemolecule-banner.png` ফাইলটি সরাসরি পেনড্রাইভে বা ইমেইলে পাঠিয়ে দিতে পারেন।

```bash
node banner/export-banners.js
```
